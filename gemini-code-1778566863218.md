# WORKFLOW FULL KONSEP: R_HMT OFC CHAT CHANNEL

## FASE 1: PERSIAPAN & INFRASTRUKTUR (THE SETUP)
Fase ini murni menyiapkan pondasi sebelum eksekusi kode.

1. Ekosistem Telegram:
   - Buka Telegram, cari BotFather. Buat bot baru dan simpan HTTP API Token.
   - Buat satu Grup Privat di Telegram. Masukkan bot ke grup dan jadikan Admin.
   - Dapatkan Chat ID dari grup privat tersebut (berfungsi sebagai "Tabel Database").
2. Ekosistem Hosting:
   - Buka GitHub, buat repositori baru (misal: chat-saluran-app).
   - Buka Vercel, import repositori GitHub tadi.
3. Setup Environment Variables (Vercel):
   - Masuk ke Settings > Environment Variables. Masukkan data krusial:
     * TELEGRAM_BOT_TOKEN = (Token dari BotFather)
     * TELEGRAM_CHAT_ID = (ID Grup Privat)
     * ADMIN_PASSWORD = (Password rahasia untuk akses log admin)
     * VITE_SESSION_STATUS = OPEN (Untuk kontrol buka/tutup sesi)

## FASE 2: SISTEM KEAMANAN & AUTENTIKASI (TANPA EMAIL)
Keamanan dikendalikan melalui validasi frontend dan Vercel Serverless.

- Validasi Anti-Spam (Frontend): 
  Formulir wajib diisi dengan format benar. Nama minimal 4 karakter (hanya huruf/angka). Password dan Konfirmasi Password wajib cocok.
- Sistem Sesi (Local Storage):
  Setelah registrasi, data `username` dan token acak disimpan di `localStorage` browser. Reload web tidak memerlukan login ulang dan mengunci identitas user agar tidak mudah diganti.
- Keamanan Admin (Backend):
  Halaman `/admin` dilindungi password. Frontend mencocokkan input dengan `ADMIN_PASSWORD` di Vercel sebelum membuka log.

## FASE 3: ARSITEKTUR BACKEND & ALUR DATA (THE ENGINE)
Memanfaatkan Vercel Serverless Functions (`/api`) untuk menjembatani frontend dan Telegram dengan aman.

- Kirim Chat Public:
  Frontend -> `/api/send` -> Cek Validitas -> Telegram API 
  (Bot mengirim format: `#PUBLIC Dari: [Nama] - [Isi Pesan]`)
- Kirim Chat Private:
  Frontend -> `/api/send` -> Cek Validitas -> Telegram API 
  (Bot mengirim format: `#PRIVATE Dari: [Nama] - [Isi Pesan]`)
- Muat Halaman (Public Feed):
  Frontend -> `/api/get` -> Ambil histori Telegram API -> Filter pesan dan hanya render yang memiliki tag `#PUBLIC`.

## FASE 4: PENGEMBANGAN UI/UX (GLASSMORPHISM)
Implementasi desain menggunakan React, Vite, dan Tailwind CSS.

- Color Palette:
  Background utama hitam pekat (#0a0a0a) dan abu-abu gelap (#171717). Aksen Hijau Neon (#39ff14) atau Ungu Elektrik (#bf00ff). Bebas dari elemen biru.
- Komponen Visual Utama:
  Chat Container menggunakan efek kaca (`bg-white/5 backdrop-blur-lg border border-white/10`). Bubble Chat didesain melayang dengan shadow halus dan modern.
- Link Preview (OG Tags Parser):
  Regex mendeteksi URL (https://...). Sistem menarik metadata web (Image Thumbnail, Title, Description) untuk dirender otomatis menjadi kartu preview di dalam bubble chat.

## FASE 5: FITUR KONTROL (THE POWER SWITCH)
Fitur kendali manual untuk mengatur ketersediaan sesi chat.

- Cara Kerja Switch: 
  Ubah Environment Variable `VITE_SESSION_STATUS` di Vercel menjadi `CLOSED`, lalu tekan Redeploy.
- Efek Tampilan:
  Form input pesan di frontend menghilang. Muncul banner glassmorphism bertuliskan: "Sesi Chat Sedang Ditutup. Pantau terus Saluran WhatsApp R_hmt ofc untuk update selanjutnya!"

## FASE 6: FINALISASI & DEPLOYMENT
Proses rilis yang efisien langsung dari repository.

1. Push Code: Commit dan push semua pembaruan kode dari lokal ke GitHub.
2. Auto-Build: Vercel otomatis mendeteksi perubahan dan melakukan proses build.
3. Live: Salin link domain Vercel yang sudah aktif, tempel di deskripsi atau postingan Saluran WhatsApp.
